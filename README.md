# 电力公司 · Power Company

> 2D 回合制「电力经营 + 证券并购博弈」模拟游戏 —— 经营电网决定财报，财报决定股价；
> 用电价战术打压对手财报、砸低对手股价，在股市收购对手壮大自己，同时提防 AI 用同样手段吞并你。

---

## 快速开始

```bash
python main.py                 # 启动：先进启动页，点【开始】进游戏
python main.py --seed 2026     # 指定地图/随机种子（换一张地形与矿脉分布）
```

启动页（国际主义版式，`docs/ui_start_screen.md`）：`↑↓` 选菜单、`Enter` 确认、
选到【设置】时 `←→` 改值、`Esc` 退出；左下状态灯绿=自检通过、红=字体/存档/版本有问题。
启动页是**盖在游戏窗口上的覆盖层**：点【开始】只是把覆盖层摘掉，同一个窗口直接变游戏，不会关窗口再开一个（全屏下也就不会闪）。
【设置 → 显示】里的"全屏"是**真全屏**（连标题栏、任务栏、菜单栏一起让位），游戏内按 `F11` 随时切换，窗口模式下回到 1240×736。

其他入口（都是开发自用工具）：
```bash
python main.py --selftest      # 无窗口自检（打包后验收用）
python tools/sim.py 48         # 无头模拟 48 回合，看数值是否健康（开发用）
python tools/sim.py 12 noisy   # 每回合打印完整利润表
python tools/balance.py 6      # 机器人跑 6 局，统计胜率与达成回合
python -m unittest discover -s tests -v   # 29 个引擎单元测试
python tools/ui_smoke.py       # 界面交互冒烟测试（建造/买股/控股/合并）
python tools/demo_shot.py 12   # 自动截图到 docs/screenshots/（需 Pillow，已 gitignore）
```

## 打包成 Windows exe

```bat
build.bat             :: 目录版 → dist\电力公司\  （推荐：启动快、杀软误报少）
build.bat onefile     :: 单文件 → dist\电力公司.exe（首次启动要解压 1~2 秒）
```

**前置**：任意 Python 3.10+（带 tkinter）。脚本会自动探测 PATH、`%LOCALAPPDATA%\Programs\Python`、
`C:\Python3*`，也会兜底用 DSH 运行时的 python；都不行就手动指定：

```bat
set PYTHON=D:\Python312\python.exe
build.bat
```

**它做六件事**：找 Python（跳过 Microsoft Store 占位程序）→ 按需抓 PyInstaller 到 `build_tools\`
→ 缺图标就现场生成 `assets\app.ico` → 先跑一次 `main.py --selftest` → PyInstaller 打包
→ 生成 `绿色小游戏告知.txt` 并打印产物 SHA-256。

**验收**（一定要用 `cmd` 调，不要用 PowerShell 的 `Start-Process -Wait`，GUI 子进程会把等待挂住）：

```bat
cmd /c "dist\电力公司\电力公司.exe --selftest"
echo %ERRORLEVEL%
type dist\电力公司\selftest.log
```

日志里应看到 `frozen=True`、`界面自检通过：窗口 …x…，地图 …x…`。当前实测产物约 29 MB。

**分发**：把 `dist\电力公司` **整个文件夹**压成 zip 即可（`_internal\` 不能少；`assets\app.ico`
已经用 `--add-data` 打进 `_internal\assets\`，标题栏图标从 `sys._MEIPASS` 读，见 `paths.resource_dir()`）。
存档写在 `%APPDATA%\PowerCompany\`，不可写时回落到 exe 同目录 `saves\`。

**常见坑**：改完代码必须重新 `build.bat`（dist 不会自动更新）；只有 Store 版 Python 会报"没找到可用
Python"；首次运行 PyInstaller 构建会联网抓包；个别杀软对 PyInstaller 产物误报，用目录版 + 告知文件里的
SHA-256 说明情况。

## 一局游戏在玩什么

| 阶段 | 你做的事 | 对应界面 |
|---|---|---|
| 观察 | 需求峰谷、煤价/铀价、政策台阶、对手财报与股价 | 左侧【政策】/【股市】 |
| 基建 | 建电厂、变电站、输电线、煤矿铀矿；招人/裁员；借款 | 底部建造条 + 【公司】→ 运营 |
| 定价 | 居民与工业分开定价：盈利定价 or 掠夺定价 | 【公司】→ 运营（滑杆） |
| 结算 | 点【结束回合】→ 供需 → 调度 → 成本 → 财报 | 【公司】→ 财报 |
| 股市 | 报告落地 → 全市场股价刷新 → K 线看走势 → 买股 / 回购 / 控股 / 合并 | 【股市】（K 线） |
| 事件 | 风暴、罢工、煤价暴涨、政策收紧、核电核准 | 【政策】→ 日志 |

## 关键机制（必须懂的四条）

1. **固定成本照扣**
   每座电厂每季度都要付折旧 + 运维，哪怕一度电都不发。产能过剩会直接吞掉利润。

2. **电网不是摆设**
   电厂必须和「城市 2 格内的变电站」通过相邻的线路连成一片（地图上黄色虚线圈 = 供电服务圈）。
   城市接口容量 = 圈内变电站 180MW + 线路 120MW 之和，线损随距离上升。
   送不出去的电 = 没有收入，但你依然付燃料和固定成本。

3. **客户看两件事：电价 + 可靠性**
   份额按 `(市场均价 / 你的价)^弹性 × 口碑` 分配，但每家拿到的份额不超过它的可交付容量。
   想抢份额必须先建产能；只降价不建厂没有意义。掠夺定价持续 3 回合并超过 55% 份额 → 反垄断处罚。

4. **财报决定股价，股价决定生死**
   股价 = 滚动四季度 EPS × PE + 净资产锚定；亏损会把股价打到净资产以下。
   5% 举牌 / 20% 董事席位 / 51% 控股（可强制分红抽血、淘汰其机组）/ 75% 吸收合并（资产债务人力全并入）。
   反过来，你负债过高、连续亏损时，AI 会低价抢客户 + 悄悄吸你的股票，持股过 51% 你就出局。

## 操作提示

- 界面分区：顶部**数据条**（现金/负债/股价/市值/市占/监管）＋右上**时间块**（回合 · 结束回合）；
  左侧**页签轨**（政策 / 股市 / 公司）＋**其它**（存档/读档/规则）；中间**地图**；底部**建造条**。
- 页签点开是盖在地图右侧的抽屉，再点一次（或按 `Esc`）收起——地图始终是主角。
- 选建筑类型 → 地图上可建地块高亮 → 点击确认；再点底部【取消】退出建造模式。
- 鼠标悬停地块看造价与不可建原因；点击城市看各公司份额。
- 股市页：上方是该公司的 K 线（每回合一根，红涨绿跌，买卖会打出上下影）；点行情表切换公司 → 填「数量（占总股本 %）」→ 公司账户 / CEO 账户买入。
- 增发是**折价配售**：发得越多折价越深（6% 起，上限 25%），发完股价直接砸到配售价——拿到现金，但股价、市值当场下跌。市值是胜利条件，别拿它换钱。
- 51% 后可【控股接管】、强制全额分红、淘汰其落后机组；75% 后可【吸收合并】。
- 快捷键：`Ctrl+Enter` 结束回合、`Esc` 退出建造/收起抽屉、`Ctrl+1~3` 开政策 / 股市 / 公司、`F11` 全屏↔窗口。
- 建造按钮会自动置灰：钱不够、没地块、核电未核准时点不动，右侧一行写明原因。
- 菜单可保存/读取进度（手动 `saves/slot1.pkl`；开启自动存档后每回合写 `saves/autosave.pkl`，两者互不覆盖）。
