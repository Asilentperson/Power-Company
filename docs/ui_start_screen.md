## 1. 风格规则（国际主义 / 瑞士风格）

1. **网格先行**：12 栏、固定栏距，所有元素吸附到栏线与 8px 网格。
2. **非对称平衡**：左窄右宽，重心压在右下，左上留白。
3. **一种无衬线**：Noto Sans SC（中文）× Arial（拉丁），不混第三种字体。
4. **字号对比极端**：118px 字标 vs 7.5px 微型标签，中间层极少。
5. **左对齐 + 错落右对齐**：所有正文左对齐；数值/元信息右对齐到同一条竖线。
6. **颜色即功能**：红=可行动，蓝=身份，黄=配置，绿=状态。色块是信息，不是装饰。
7. **零装饰**：没有阴影、圆角、渐变、描边图标。分割线只有 1px。

## 6. 状态灯

| 状态 | 色条/点 | 主行 | 副行 |
|---|---|---|---|
| 正常 | `#35C15A` | 文字校对成功 · 可联机 / 单机模式 | `v1.0.0 · BUILD 2026.05.01` |
| 异常 | `#E1251B` | 文字校对失败 · 离线 | 同上 |
| 校验中 | `#55555C` | 正在校验… | 同上 |

> **"可联机"不是硬编码**：主行尾巴由 `constants.MULTIPLAYER_READY` 决定。
> 联机模块尚未接入（当前为 `False`），所以实际显示"单机模式"；
> 等网络层落地后把它翻成 `True`，文案自动变成"可联机"，UI 不用改。

规则：

- 自检项 = 字体可用 / 语言包存在 / 存档目录可写 / 版本号匹配；任一失败即切红。
- 红态时"继续"自动禁用（文字 `#3E3E45`，右侧 meta 变"无存档 · NO SAVE"），**不给点击机会**。
- 状态灯不接受点击，只做提示；点它 = 打开"关于"里的自检详情。

## 7. 交互

| 输入 | 行为 |
|---|---|
| `↑` `↓` | 在 4 项间移动，跳过禁用项 |
| `Enter` / `Space` | 激活；"开始"直接进游戏 |
| `Esc` | 从设置编辑态退回菜单；在菜单按 `Esc` 弹退出确认 |
| 鼠标悬停 | 该行左缘出现 2px 红条（不改变底色） |
| 选中"开始" | 默认态；黄块为**只读预览**，右上角写"当前配置 · 按 3 修改" |
| 选中"设置" | 黄块获得焦点，右上角改为"正在编辑"，`←→` 改值，行尾出现 `‹ ›` |
| 选中"继续" | 显示存档摘要（第 N 回合 / 现金 / 市值）覆盖在黄块内 |
| 选中"关于" | 黄块内显示版本、致谢、自检详情 |

**设置项固定 6 行，顺序不可变**：语言 / 显示 / 音频 / 难度 / 自动存档 / 数据校验。
第 6 行"数据校验"是状态灯的数据来源，二者必须同源，不许各算一套。

## 8. 落地实现（已接通）

| 文件 | 职责 |
|---|---|
| `pwer/ui/start.py` | 启动页本体：`StartScreen(tk.Frame)`，是盖在游戏窗口上的**覆盖层**，全部用 Canvas 画，无位图 |
| `pwer/ui/prefs.py` | 偏好读写（`settings.json`，与存档同目录），读坏了回落默认值 |
| `main.py` | 入口 `App(show_start=True)`：一个窗口从启动页跑到游戏，**不销毁重建** |
| `pwer/ui/app.py` | `App(show_start=..., seed=...)`；`open_start()` 铺覆盖层，点【开始】只 `destroy` 覆盖层；自动存档写 `autosave.pkl`（与手动 `slot1.pkl` 分开） |

### 8.1 设计稿 → 实现的关键映射

| 需要 | 实现 |
|---|---|
| 单窗口 | 启动页是 `place(relwidth=1, relheight=1)` 的覆盖层，点【开始】后 `destroy` 自己、`unbind` 按键，游戏界面本来就在下面——不会"关一个窗口再开一个" |
| 菜单栏 | 启动页期间 `config(menu="")`，进游戏后按全屏设置恢复；全屏时菜单栏整体隐藏（Windows 下它不吃 `-fullscreen`，会留 39px 白条） |
| 等比缩放 | `k = min(w/1920, h/1080)`，居中留黑边；`_k` 变化时清字体缓存 |
| 1px 线 | 统一 `create_line(width=max(1, k))`；细线不靠描边矩形，避免 DPI 下变 2px |
| 字距 | Tk 不支持 letter-spacing → 逐字符 `create_text`，按 `font.measure()` 推进 |
| 字号下限 | `max(7, round(px*k))`：小屏（1260×840）上 7.5px 的微排版也不会糊成噪点 |
| 字体回退 | `Noto Sans SC Black/Medium` → `Microsoft YaHei UI`；回退时用 `weight=bold` 顶替 Black |
| 自检 | 字体 / 存档目录可写 / 版本格式 三项，`StartScreen.check` 同时喂状态灯与第 6 行 |
| 存档 | 启动页扫 `slot1.pkl` 与 `autosave.pkl`，取 mtime 更新的那个；损坏则跳过 |

### 8.2 设置项的真实状态（不装样子）

| 行 | 取值 | 是否真的生效 |
|---|---|---|
| 01 语言 | 简体中文 | 仅中文（多语言未接入），不可改 |
| 02 显示 | 全屏 / 窗口 | **生效**：立即切换启动页显示方式并写入 `settings.json` |
| 03 音频 | 未接入 | 游戏无音频系统，明写"未接入"，不给假开关 |
| 04 难度 | 标准 | 引擎没有难度分级，不可改 |
| 05 自动存档 | 开 / 关 | **生效**：开启后每回合写 `autosave.pkl` |
| 06 数据校验 | 通过 / 失败 | **生效**：与状态灯同源 |

> 原则：能真做的就做（显示、自动存档），不能做的写"未接入"，
> 而不是摆一个点了没反应的开关——这比少两个设置项更伤信任。

## 11. 应用图标（与标题块同一套几何）

**锁形（start screen 标题块）** = 白框 + 闪电；**应用图标** = 去掉白框，只留闪电。
原因：16~32px 下白框会退化成双色糊边（对照图 B 组），而闪电本身在 16px 仍然可辨（A 组）。

| 项 | 值 |
|---|---|
| 画布 | 512 × 512，满幅纯色，**无圆角**（瑞士风格不用圆角） |
| 底色 | `#21449C`（与标题块同一蓝） |
| 闪电 | 与 `pwer/ui/start.py` **同一组 6 个点**，高 72% 画布、居中、`#F4F2EC` |
| 白框 | 图标**不用**；仅在标题块里作为 lockup 出现 |
| 抗锯齿 | 4× 超采样后 LANCZOS 降采样（16px 斜边不出台阶） |
| 产物 | `assets/app.ico`（16/24/32/48/64/128/256）、`assets/app_512.png`（商店/宣传） |
| 生成 | `python tools/make_icon.py`（同时输出对照预览 `docs/screenshots/app_icon_preview.png`） |
| 挂载 | `pwer/ui/__init__.py::set_window_icon()`：ico 优先、png 兜底、缺失静默跳过 |

> 图标是**生成物**，`assets/` 已在 `.gitignore` 里；`tools/` 只放生成脚本，不落任何游戏资源。
